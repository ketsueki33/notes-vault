
| Action                              | Shortcut                        | Description                                                                             |
| ----------------------------------- | ------------------------------- | --------------------------------------------------------------------------------------- |
| Closing all open tabs               | `CTRL + K` -> `CTRL + W`        |                                                                                         |
| Expand/ Collapse current code block | `CTRL + K` -> `CTRL + L`        | Expand or Collapse a code block, such as a function or a class.                         |
| Collapse Code blocks                | `CTRL + K` -> `CTRL + 1/2/3...` | Collapse all code blocks at a certain indentation level corresponding to pressed number |
| Expand All Code Blocks              | `CTRL + K` -> `CTRL + J`        | Expand all code blocks recursively                                                      |
| Go to a specific line               | `CTRL + G`                      |                                                                                         |
